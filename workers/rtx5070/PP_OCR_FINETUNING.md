# PP-OCRv6 卡密字体微调流程

本流程只处理人工确认的真实图片字体、版式和清晰度特征，不记忆一次性卡密，
也不自动修改生产识别结果。

## 数据生成

```bash
python scripts/build_ppocr_training_dataset.py
```

默认输入为 `benchmarks/ocr/private/gold/manifest.json`，输出到
`benchmarks/ocr/private/ppocr-training/`。该目录已被 Git 忽略。

自动标签仅包含：

- 图片哈希已校验；
- 人工确认的单张 PUBG 卡密；
- 能安全裁剪为单行文字区域；
- 无 PSN、无多卡、无待复核状态。

多卡图或无法安全裁剪的图片只进入 `needs_annotation.json`，不得直接用于训练。

## 上线边界

1. 新模型先离线训练，不替换 `D:\gpu_ocr` 当前模型。
2. 使用完整私有金标准库比较旧模型与新模型。
3. 漏识别、误识别、PUBG/PSN 串类、顺序错误任一增加时禁止上线。
4. 新模型先以影子模式运行，保存模型版本、原始文本、坐标、置信度和耗时。
5. 只有人工批准后才切换生产模型，并保留旧模型目录用于立即回滚。

禁止全局字符替换、格式猜字、跨行跨卡拼接，以及把完整历史卡密作为规则。
